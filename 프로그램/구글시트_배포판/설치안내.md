# 차량 지킴이 구글 시트판 설치 안내

센터 구글 계정 하나로 **한 번만** 설치하면 됩니다. 10분쯤 걸립니다. 설치가 끝나면 선생님들은 로그인 없이 주소와 센터 암호만으로 씁니다.

> 이 안내대로 실제 구글 계정에 설치해 시범 사용 중입니다(2026-11). 구글이 화면을 바꾸면 메뉴 이름이 조금 다를 수 있으니, 비슷한 이름을 찾아 주세요.

## 1. 새 스크립트 만들기

1. 센터 구글 계정으로 로그인합니다.
2. 주소창에 `script.new` 를 적고 엔터를 누릅니다. Apps Script 편집 화면이 열립니다.
3. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 `차량 지킴이`로 바꿉니다.

## 2. 코드 붙여 넣기 (파일 하나)

1. 편집 화면의 `Code.gs` 안에 있는 내용을 모두 지웁니다.
2. 이 폴더의 `Code.gs`를 메모장으로 열어 전체 선택(Ctrl+A), 복사(Ctrl+C)한 뒤 편집 화면에 붙여 넣습니다(Ctrl+V).
3. 저장(Ctrl+S)을 누릅니다.

## 3. 시간대 맞추기

왼쪽 톱니바퀴(프로젝트 설정)에서 **시간대**를 `(GMT+09:00) 서울`로 맞춥니다. 날짜 계산이 한국 시간으로 됩니다.

## 4. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
3. **다음 사용자 인증 정보로 실행**: `나`
4. **액세스 권한이 있는 사용자**: `모든 사용자`
   - 이렇게 해야 선생님들이 로그인 없이 열 수 있습니다. 대신 5번에서 정하는 센터 암호가 문을 지킵니다.
5. **배포**를 누릅니다. 권한을 묻는 창이 나오면 센터 계정을 고르고 허용합니다.
   - "Google에서 확인하지 않은 앱"이라고 나오면 **고급 → 차량 지킴이(으)로 이동**을 누릅니다. 직접 만든 스크립트라서 나오는 안내입니다.
6. 나온 **웹 앱 URL**을 복사합니다. 이 주소가 차량 지킴이 주소입니다.

## 5. 처음 열고 센터 암호 정하기

1. 복사한 주소를 PC 브라우저에서 엽니다.
2. "센터 암호 정하기" 창이 나오면 숫자 4자리 이상의 암호와 내 이름을 적습니다. **가장 먼저 연 사람이 암호를 정하게 되므로, 주소를 다른 사람에게 알리기 전에 직접 먼저 여세요.**
3. 차량을 등록합니다.
4. 다른 선생님에게 주소와 암호를 알려 줍니다. 휴대폰에서 주소를 열고 암호를 한 번 적으면 그 휴대폰이 기억합니다.
   - 휴대폰 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생깁니다.
5. 머리말 오른쪽에 `구글 시트에 저장 중`이라고 나오면 된 것입니다. 휴대폰에서 적은 기록은 PC 화면에 20초 안에 나타납니다.

## 6. 매주 월요일 알림 메일 켜기 (선택)

1. Apps Script 편집 화면 위쪽의 함수 고르기에서 `installWeeklyReminder`를 고르고 **실행**을 누릅니다. 권한을 묻으면 허용합니다.
2. 매주 월요일 오전 8시대에, 지났거나 곧 챙길 항목이 있을 때만 메일이 옵니다. 받는 사람은 설치한 계정과, 앱의 [설정] → 센터 → "알림 메일 받을 주소"에 적은 주소입니다.
3. 바로 시험해 보려면 `sendReminder`를 고르고 실행합니다.

## 기록은 어디에 있나요

스크립트가 센터 구글 드라이브에 `차량 지킴이 기록`이라는 스프레드시트를 스스로 만듭니다. 시트는 차량, 운행일지, 정비기록, 운전자, 설정, 변경이력 6개입니다.

- 맨 오른쪽 `원본` 칸은 앱이 읽는 값입니다. 고치지 마세요. 기록을 고칠 때는 앱 화면에서 고칩니다.
- `변경이력` 시트에는 누가 언제 무엇을 고치거나 지웠는지, 바꾸기 전 값이 남습니다.
- 가끔 **파일 → 사본 만들기**로 사본을 남겨 두세요.

## 주의

- 주소와 암호를 아는 사람은 누구나 기록을 읽고 쓸 수 있습니다. 여러 사람이 보는 곳에 둘을 함께 올리지 마세요. 선생님이 그만두면 [설정] → [센터 암호 바꾸기]로 바꾸세요.
- 암호를 잊었다면: Apps Script 편집 화면 → 프로젝트 설정 → 스크립트 속성에서 `PIN`을 지우고 주소를 다시 열어 새 암호를 정합니다.
- 배포 주소를 잊었다면: Apps Script 편집 화면 → **배포 → 배포 관리** → 웹 앱 **URL** 옆 [복사]를 누르면 됩니다. 주소는 새 버전으로 다시 배포해도 바뀌지 않습니다.
- 코드를 새 판으로 바꿀 때는 `Code.gs`를 통째로 다시 붙여 넣고 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 합니다. 주소는 그대로입니다.
