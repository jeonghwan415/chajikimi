# 차량 지킴이 사용 설명서 (v4)

지역아동센터 차량의 점검 시기를 한 화면에서 알려 주고 운행일지를 쉽게 적는 도구입니다. AI를 쓰지 않고 정해진 규칙으로만 계산합니다.

## v4에서 바뀐 것 (시범 사용 의견 반영, 2026-11-13)

| 들은 의견 | 바꾼 것 |
|---|---|
| 수기가 익숙하고 앱·PC 입력은 낯설다 | ① 오늘 화면의 **「자주 하는 운행 바로 적기」**: 지난번 같은 운행(등원·하원 등)을 미리 채움. 도착 km와 확인 칸만 보면 됨 ② PC [운행일지] 탭 표 맨 아래 **노란 줄(표에 바로 적기)**: 종이 일지처럼 한 줄씩 적고 Enter로 저장. 종이에 먼저 적고 나중에 옮겨 적어도 됨 |
| 영수증 붙이는 양식이 있으면 좋겠다 | [점검·정비] 탭 **「+ 주유·구입 기록하기」**, 정비 기록의 **「저장하고 영수증 양식 인쇄」**, 이력 표의 **「양식 인쇄」**, **「빈 영수증 양식 인쇄」**. 양식은 A4 세로, 왼쪽 원본·오른쪽 사본 칸. [운행일지] 탭 **「청구용 인쇄 (일지+영수증)」**는 그 달 운행일지 + 지출 내역(합계) + 영수증 양식을 한 번에 인쇄 |
| 첫 화면에 점검 아이콘이 많아 복잡하다 | 오늘 화면은 운행 기록 → 바로 적기 → 최근 운행 순서. 점검 타일은 **「차량 점검 · 정비 알림」 폴더** 하나로 접어 두고, 누르면 펼침(기기가 기억). 지난 것·곧 챙길 것 개수는 접힌 상태에서도 보임 |
| 바탕화면에 두는 법을 알려 달라 | 머리말 **[사용 방법]** 단추(바탕화면·휴대폰 홈 화면에 두는 법 + 매일 쓰는 법, 인쇄 가능). 나눠 줄 문서: `08_바탕화면_설치_안내.docx` (한글 파일은 `한글파일` 폴더) |

- 주유·세차 같은 지출은 정비기록 시트에 함께 저장되고, 점검 주기 계산에는 쓰이지 않습니다. 시트의 `항목` 칸은 이제 `oil` 대신 `엔진오일·오일필터`처럼 읽기 쉬운 이름으로 적힙니다(새로 적는 기록부터).
- 구글 시트판을 쓰고 있다면 `구글시트_배포판/Code.gs`를 다시 붙여 넣고 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 바뀐 화면이 보입니다. 주소와 기록은 그대로입니다.
- v3 원본은 `_v3_백업` 폴더에 있습니다.
- (v4.1, 2026-11-13) **시간은 5분 단위**로 고릅니다(시·분 두 칸). 예전에 1분 단위로 적은 기록도 그대로 보입니다.
- (v4.1) **유류수불대장**: 지역아동센터 운영지침의 유류수불대장 칸(연번·일자·주유량·금액·주행거리·비고·결재 담당/시설장)을 따른 A4 세로 양식. [운행일지] 탭 [유류수불대장 인쇄], 청구용 인쇄에도 들어갑니다. 주유 기록에 **주유량(리터)**과 그때 km를 적으면 채워집니다.
- 센터 암호 칸은 ●로 가려지고, 오른쪽 눈 단추를 누르면 보입니다. 화면 맨 아래에 "만든 사람: jeong hwan · 무단 배포 금지"가 있습니다.
- **테스트용 사이트**: https://jeonghwan415.github.io/chajikimi-demo/ (로그인 없음, 기록은 여는 사람 기기에만 저장. `소스/build/demo/index.html`을 공개 저장소 `jeonghwan415/chajikimi-demo`에 올린 것)

## 처음 시작하기

1. [차량 등록하기]를 누르고 차 이름, 지금 계기판 숫자(km), 연료를 적습니다.
2. 자동차등록증의 검사 유효기간 만료일, 보험증권의 만기일을 적습니다. 모르면 비워 두고 나중에 적어도 됩니다.
3. [설정]에서 센터 이름, 결재란, 운전하는 선생님 이름과 통학버스 안전교육을 받은 날을 적습니다.
4. 오늘 화면의 [한 번에 적기]를 눌러, 정비 명세서나 앞 유리 스티커를 보고 아는 항목만 마지막 교환일과 그때 km를 적습니다.

## 매일 하는 일

운행을 마치면 [오늘 운행 기록하기]를 누릅니다. 적는 칸은 이렇습니다.

- 일자, 출발 시간, 도착 시간 (도착 시간은 지금 시각이 미리 들어가 있습니다)
- 운행 목적
- 운행 거리: 도착했을 때 계기판 숫자만 적으면 계산됩니다. 출발 숫자는 지난번 도착 숫자로 미리 들어가 있습니다.
- 운전자 확인, 동승자 확인
- 차량 점검 내용: 6가지를 보고 [모두 이상 없음]을 누르거나, 이상이 있으면 적습니다.

**[저장하기]를 눌러야 기록이 남습니다.** 저장하지 않고 닫아도 쓰던 내용은 그 기기에 보관되고, 오늘 화면 위에 "저장하지 않은 운행 기록이 있어요"라고 나옵니다. [이어서 쓰고 저장하기]를 누르세요.

## 오늘 화면 읽는 법

- 맨 위에서 노란 차 캐릭터 노랑이가 말해 줍니다. 예: "점검할 시기예요. 신경 써 주세요!"
- 그 아래 타일이 항목 하나씩입니다. 빨강 "지났어요", 주황 "곧 챙기기", 흰색 "정상", 점선 "기록 필요".
- 타일의 동그라미는 주기를 얼마나 썼는지 보여 줍니다.
- 타일을 누르면 계산 근거가 나옵니다. 예: `마지막 교환 52,000km + 주기 10,000km = 62,000km, 지금 61,431km`

- 맨 아래에 이번 철(겨울철, 장마철 등)에 챙길 것이 한 줄로 나옵니다. [챙길 것 보기]를 누르면 쉬운 말로 풀어 줍니다.

## 주기는 참고값입니다

화면의 주기는 일반 권장값입니다. 차량 취급설명서와 다르면 [설정] → [점검 주기 고치기]에서 바꾸고 "차량 설명서로 확인했어요"에 표시하세요. 차 상태에 대한 판단은 정비소가 우선입니다.

## 시범 사용과 의견 모으기

- 머리말 오른쪽 **[의견 보내기]**로 선생님이 쓰기 쉬웠는지(5단계), 지금 방식으로 운행일지 1건 쓰는 시간, 헷갈린 것, 좋았던 점, 바라는 점을 보냅니다. 구글 시트판과 웹 링크판에서만 보입니다.
- 의견은 구글 시트의 **`의견`** 시트에 쌓입니다. 화면으로는 돌려보내지 않아서 다른 선생님은 볼 수 없습니다.
- 새로 적은 운행 기록마다 **작성 시간(초)**이 `운행일지` 시트에 남습니다. PRD의 성공 기준(운행 1건 1분 안)을 이 숫자로 확인합니다.
- 선생님께 드릴 안내문: `07_시범사용_안내.docx` (한글 파일은 `한글파일` 폴더). 접속 QR은 `프로그램/접속_QR.png`.

## 한글(.hwp) 파일로 저장하기

- **운행일지**: [운행일지] 탭의 [한글 파일 저장]을 누르면 그 달 운행일지가 `.hwpx` 한글 파일로 저장됩니다. 결재란과 표가 들어 있고, 한글 2014 이후 버전에서 열립니다. 구글 시트판과 파일판에서 쓸 수 있습니다(Claude 웹 링크판에는 없습니다).
- **.hwp가 꼭 필요하면**: 한글에서 `.hwpx` 파일을 연 뒤 [파일] → [다른 이름으로 저장] → 파일 형식을 `한글 문서(*.hwp)`로 고르면 됩니다.
- **문서 01~06**: `한글파일` 폴더에 `.hwpx`로 바꿔 둔 것이 있습니다.
- **구글 문서(Google Docs)에 있는 글**: 구글 문서는 한글 파일로 바로 저장하지 못합니다. [파일] → [다운로드] → `Microsoft Word(.docx)`로 받은 뒤, 한글에서 열어 [다른 이름으로 저장] → `.hwp`로 저장하세요.
- 한글 파일은 자동 검사(한글 파일 규격 검사)를 통과했지만, 실제 한글 프로그램에서 열어 보는 확인은 아직 하지 못했습니다. 모양이 어긋나면 알려 주세요.

## 기록이 날아가지 않게

- 구글 시트판: 인터넷이 끊기면 기기에 보관했다가 다시 보냅니다. 머리말에 "보내지 못한 기록 ○건"이 보이면 인터넷이 되는 곳에서 화면을 열어 두세요.
- 파일판: 기록이 10건 쌓일 때마다 "백업해 두세요"라고 나옵니다. [백업 파일 저장]을 눌러 파일을 보관하세요.

## 고치는 사람에게

- `소스/src/rules.js`가 주기와 계산식의 유일한 원본입니다. 화면은 `src/ui.js`, 틀과 모양은 `src/page.html`, 구글 시트 서버 코드는 `src/gas_tail.js`입니다.
- `소스` 폴더에서 `node build.js`를 돌리면 `app.html`(웹 링크판 본문), `build/차량지킴이.html`(파일판), `build/Code.gs`(구글 시트판)가 만들어집니다.
- 한글 파일: `src/hwpx.js`(운행일지 → .hwpx), `docx2hwpx.py`(문서 .docx → .hwpx, `pip install python-hwpx python-docx` 필요). `node hwpxtest.js`로 예시 운행일지를 한글 파일로 만들어 볼 수 있습니다.
- 테스트: `node src/rules.test.js`(규칙 24개), `node gastest.js`(서버 17개), `node test.js`(브라우저 34개, Playwright 필요). 고친 뒤 셋 다 돌리세요.
- 부족한 점과 남은 일은 `05_핸드오프_5팀.docx`의 6번, 8번에 있습니다.
